## Project Overview

Mad Libs is a word-substitution game that allows users to enter words such as nouns, verbs, and adjectives to create funny and entertaining stories.

## Project Goals

- Practice Java programming fundamentals.
- Use variables and user input to generate dynamic stories.
- Collaborate through GitHub.
- Test and debug code to ensure functionality.
